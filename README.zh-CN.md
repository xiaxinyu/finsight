# FinSight — 个人财务智能引擎

语言: 中文 | [English](README.md)

> 理解你的钱，理解你自己。

FinSight 将原始的银行交易数据转化为深度的个人洞察。
它会自动分类支出、构建你的财务画像，并基于你的数据帮助你做出更聪明的决策。

不依赖云。不做追踪。只提供纯粹洞察。

![仪表盘预览](https://via.placeholder.com/800x400?text=FinSight+Dashboard+Preview)

---

## 🌟 核心特性

- 🔍 智能交易分类  
  通过规则引擎与正则匹配，支持对银行/支付宝/微信等 10+ 年交易数据进行分类。
- 👤 个人财务画像  
  构建你的独特“消费 DNA”——你是储蓄型、投资型还是体验型？
- 📊 时间序列行为分析  
  月度趋势、季节性模式、异常检测（基于 ECharts）。
- 💡 AI 建议  
  可执行的建议示例：“每月减少咖啡支出 ¥200 → 为旅行攒钱”。
- 🛡️ 100% 本地与隐私保护  
  你的数据始终保留在你的设备上。
