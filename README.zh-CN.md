## 定位

FinSight 将银行与卡片流水转化为**可分类、可对账、可报表**的财务信息，由您**全程掌控数据链路**。产品面向需要**清晰视图与专业归类**、同时**不愿将核心数据交给第三方云端**的个人或小团队。

## 核心价值

- **交易与归类** — 支持导入、规则与报表，适配长期历史数据管理。
- **报表与分析** — 收支趋势、下钻与复盘，便于经营级查阅。
- **隐私与可控** — 自建部署；凭据与密钥通过环境变量等方式注入（源码中不固化敏感信息）。
