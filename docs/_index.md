# FinSight Documentation

This repository follows a Kubernetes-style documentation structure (Docs-as-Code, user-oriented layering).

## Start here

- **User docs** (learn and do)
  - [Concepts](user/concepts/)
  - [Tasks](user/tasks/)
  - [Tutorials](user/tutorials/)
  - [Setup](user/setup/)
- **Technical docs** (deploy, operate, extend)
  - [Reference](tech/reference/)
  - [Architecture](tech/architecture/)
  - [Contributing](tech/contributing/)

## How to navigate

- **Concepts**: what/why; no step-by-step procedures
- **Tasks**: how to do something; copy-pastable commands/config; includes verification
- **Reference**: structured lookup (fields/flags/parameters/APIs)
