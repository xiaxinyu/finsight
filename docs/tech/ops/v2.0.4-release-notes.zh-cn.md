---

## 概述

v2.0.4 面向**多用户、自托管**场景加固 FinSight：账本按用户隔离、RBAC 管理端 API、CSRF 与登录限流，以及完整的 **Users** 管理能力。**Debt Trends** YoY 报表新增「当前欠多少」「每年增还是减」——展示估算余额与年度方向标签。

**数据库迁移：** V50（角色初始化）· V51（账本归属回填）· V52（`xiaxinyu` 开发密码修复 — 生产部署前请审阅）。

---

## 新功能

### 按用户隔离账本数据

业务数据（交易、账单、卡片、报表、规划等）通过 `LedgerUserScope` 与 MyBatis `created_by` 条件隔离。

| 范围 | 行为 |
| :--- | :--- |
| 交易 / 导入 | 仅可查看、编辑、删除本人数据 |
| Dashboard / 报表 / 分析 | 聚合按 owner 过滤 |
| 账单 / 转账 / 卡片 | 写操作校验归属 |
| **Admin 角色** | 管理用户、卡片、规则、分类 — **不能**浏览他人账本 |

**V51** 将升级前已有数据回填为 owner `xiaxinyu`（单用户且主账号为该用户时可直接使用）。

### 用户与角色管理

| 功能 | 路径 / API |
| :--- | :--- |
| **用户管理** | `/app/admin/users` — 搜索、新建、编辑角色、启用/禁用、重置密码、删除 |
| **账户与安全** | `/app/settings/account` — 自助修改密码 |
| **登录身份展示** | 顶栏账户菜单 — 显示名、@用户名、角色 |
| **密码策略** | 至少 8 位，含字母与数字（新建 / 重置 / 修改密码） |

**API：**

- `GET /api/v1/users?q=` — 用户列表（ADMIN）
- `POST/PUT/DELETE /api/v1/users` — 增删改（ADMIN）
- `POST /api/v1/users/{id}/reset-password` — 管理员重置（ADMIN）
- `POST /api/v1/auth/change-password` — 本人改密（已登录）
- `GET /api/v1/auth/me` — 新增 `displayName`、`roles`、`admin`

后端：`UserAdminService`、`PasswordPolicy`；用户表审计字段 `created_by` / `updated_by`。

### Debt Trends — 余额与年度增减

| 增强 | 说明 |
| :--- | :--- |
| **当前欠款** | 信用卡 / 负债类账户余额合计（与 Wealth 同源） |
| **区间变化** | 相对历史窗口起点的估算增减 |
| **余额轨迹图** | 从当前余额按分类借贷/还款流水反推各年估算余额 |
| **年度标签** | 每年 **Debt up** / **Debt down** / **Stable** |
| **净流量图** | 按方向着色，零线基准 |

路径：`/app/reports/debt-trends` · API：`GET /api/v1/analytics/debt-trends`（扩展 `debtBalance`、`debtYearSeries` 字段）。

## 安全

| 控制项 | 说明 |
| :--- | :--- |
| **RBAC** | V50 初始化 `ADMIN` / `USER`；升级时为现有用户授予角色 |
| **CSRF** | 生产 profile 默认开启；SPA 携带 `X-XSRF-TOKEN` |
| **登录限流** | 每 IP 15 分钟内最多 8 次失败（可配置） |
| **管理 API** | 用户维护接口 `@PreAuthorize` |
| **数据保护** | 接口不返回密码哈希；卡号脱敏策略不变 |

详见 [SECURITY.zh-cn.md](../SECURITY.zh-cn.md)。

```bash
mvn clean package

# 重启 Spring Boot
```

### 迁移说明

| 迁移 | 用途 | 运维注意 |
| :--- | :--- | :--- |
| **V50** | 初始化 `ADMIN` / `USER` | 幂等，无需手工操作 |
| **V51** | 现有账本 `created_by` / `updated_by` 回填为 `xiaxinyu` | 确认主账号用户名；生产前如不同请改脚本 |
| **V52** | 将 `xiaxinyu` 密码设为 `123456` | **生产环境请删除或改密** — 部署后用「账户与安全」或管理员重置 |

**建议验证：**

```bash
mvn test -Dtest=DebtTrendAnalysisServiceTest,LedgerUserScopeTest,PasswordPolicyTest
cd frontend && npm run build
```

**手工冒烟：**

- [ ] 普通用户登录 — 仅见本人交易/报表；无 Admin 菜单
- [ ] Admin 登录 — Users 增删改、重置密码；不能看他人交易
- [ ] 顶栏显示正确的显示名 / 用户名
- [ ] 设置 → 账户与安全 — 改密（新密码须符合策略）
- [ ] 报表 → Debt Trends — 余额概览、年度方向标签、余额图
- [ ] 生产：带 CSRF token 的写操作正常（`/api/v1/auth/csrf`）

---

## 行为变更 / 注意事项

- **新建 / 重置密码**须含字母与数字（8 位以上）；旧密码在主动修改前仍可用。
- **多用户库**中报表合计可能与旧版不同：由全局聚合改为按用户聚合。
- **V51** 将历史数据归属 `xiaxinyu`；多用户上线前请确认 owner 映射。
