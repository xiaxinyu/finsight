## Summary

v2.0.4 hardens FinSight for **multi-user, self-hosted** deployments: per-user ledger isolation, RBAC-backed admin APIs, CSRF and login throttling, and a full **Users** admin experience. The **Debt Trends** YoY report now answers “how much do I owe?” and “did debt go up or down each year?” with estimated outstanding balance and yearly direction tags.

**Database migrations:** V50 (roles bootstrap) · V51 (ledger owner backfill) · V52 (optional dev password fix for `xiaxinyu` — review before prod).

---

## New features

### Per-user ledger isolation

Business data (transactions, statements, cards, reports, planning) is scoped to the **logged-in user** via `LedgerUserScope` and `created_by` filters in MyBatis queries.

| Area | Behavior |
| :--- | :--- |
| Transactions / imports | List, edit, delete only own rows |
| Dashboard / reports / analytics | Aggregates filtered by owner |
| Statements / transfers / cards | Mutations guarded by ownership |
| **Admin role** | Manages users, cards, rules, categories — **does not** browse other users’ ledger data |

**Migration V51** backfills existing rows to owner `xiaxinyu` on upgrade (safe for single-user installs that already use that account).

### User & role administration

| Feature | Path / API |
| :--- | :--- |
| **Users admin** | `/app/admin/users` — search, create, edit roles, enable/disable, reset password, delete |
| **Account & security** | `/app/settings/account` — self-service password change |
| **Session identity** | Header account menu — display name, @username, roles |
| **Password policy** | Min 8 chars, letter + digit (create / reset / change password) |

**APIs:**

- `GET /api/v1/users?q=` — list users (ADMIN)
- `POST/PUT/DELETE /api/v1/users` — CRUD (ADMIN)
- `POST /api/v1/users/{id}/reset-password` — admin reset (ADMIN)
- `POST /api/v1/auth/change-password` — self change (authenticated)
- `GET /api/v1/auth/me` — adds `displayName`, `roles`, `admin`

Backend: `UserAdminService`, `PasswordPolicy`; user mapper audit fields (`created_by` / `updated_by`).

### Debt Trends — outstanding balance & yearly direction

| Enhancement | Description |
| :--- | :--- |
| **Outstanding debt today** | Sum of credit / liability card balances (same source as Wealth) |
| **Period change** | Estimated Δ since history window start |
| **Estimated balance chart** | Year-end balance inferred by walking back from today using classified borrowing/repayment flows |
| **Year strip tags** | **Debt up** / **Debt down** / **Stable** per calendar year |
| **Net flow chart** | Color-coded by direction; zero baseline |

Path: `/app/reports/debt-trends` · API: `GET /api/v1/analytics/debt-trends` (extended `debtBalance`, `debtYearSeries.*` fields).

## Security

| Control | Notes |
| :--- | :--- |
| **RBAC** | V50 seeds `ADMIN` / `USER`; existing users receive both on upgrade |
| **CSRF** | Enabled on prod profile (`finsight.security.csrf-enabled=true`); SPA sends `X-XSRF-TOKEN` |
| **Login rate limit** | 8 failures / 15 min per IP (configurable) |
| **Admin API guard** | `@PreAuthorize` on user maintenance endpoints |
| **Data protection** | Password hashes never returned; PAN masking unchanged |

See [SECURITY.md](../SECURITY.md) for prod checklist.

## Upgrade

```bash
mvn clean package
# Flyway runs V50–V52 on startup
# restart Spring Boot
```

### Migration notes

| Migration | Purpose | Operator action |
| :--- | :--- | :--- |
| **V50** | Bootstrap `ADMIN` / `USER` roles | None — idempotent |
| **V51** | Set `created_by` / `updated_by` to `xiaxinyu` on existing ledger data | Confirm owner username matches your primary user; edit script if needed before prod |
| **V52** | Reset `xiaxinyu` password to `123456` | **Remove or change in production** — use Account & security or admin reset after deploy |

**Suggested checks:**

```bash
mvn test -Dtest=DebtTrendAnalysisServiceTest,LedgerUserScopeTest,PasswordPolicyTest
cd frontend && npm run build
```

**Smoke test:**

- [ ] Log in as non-admin — only own transactions/reports; no Admin menu
- [ ] Log in as admin — Users CRUD, reset password, cannot see another user’s transactions
- [ ] Header shows correct display name / username
- [ ] Settings → Account & security — change password (new password must meet policy)
- [ ] Reports → Debt Trends — outstanding balance hero, yearly direction tags, balance chart
- [ ] Prod: mutating API calls succeed with CSRF token from `/api/v1/auth/csrf`

---

## Breaking / behavior changes

- **New / reset passwords** must include letters and digits (8+ chars). Existing passwords remain valid until changed.
- **Report totals** may differ for multi-user DBs: previously global aggregates are now per-user.
- **V51** assigns historical data to `xiaxinyu`; multi-user installs should verify owner mapping before go-live.
