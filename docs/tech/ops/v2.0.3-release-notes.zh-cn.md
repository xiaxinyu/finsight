# v2.0.3 发布说明

| | |
| :--- | :--- |
| **Language** | 简体中文 · [English](v2.0.3-release-notes.md) |
| **基于** | v2.0.2 |
| **发布日期** | 2026-06 |

**主题：** 年度趋势分析三件套 + 报表体验升级 + Reports 导航重构

---

## 概述

v2.0.3 在 v2.0.2 财务语义层之上，补齐 **收入 / 消费 / 负债** 三条日历年 YoY 分析链路，重构 **Consumption Trends** 页面与 **Reports 侧边栏** 信息架构。所有趋势报表沿用同一 semantic layer，与 Dashboard / Cashflow 口径一致。

**无数据库迁移** — 纯应用层与前端变更。

---

## 新功能

### 年度趋势报表（Year-over-year trends）

| 报表 | 路径 | 说明 |
| :--- | :--- | :--- |
| **Income Trends** | `/app/reports/income-trends` | 日历年 Real income YoY；Reporting Classification / Category L1 矩阵；drill-down |
| **Consumption Trends** | `/app/reports/trend-changes` | 生活消费 YoY；本版页面大幅改版 |
| **Debt Trends** | `/app/reports/debt-trends` | 借贷、还款、净负债流 YoY；负债压力提示 |

**新增 API：**

- `GET /api/v1/analytics/income-trends?fromYear=&toYear=&historyFromYear=`
- `GET /api/v1/analytics/debt-trends?fromYear=&toYear=&historyFromYear=`
- `GET /api/v1/analytics/trends` — 消费趋势增强（矩阵历史年份、drill 上下文）

后端：`IncomeTrendAnalysisService`、`DebtTrendAnalysisService`；扩展 `FinanceSemanticMetricsRepository` 聚合 SQL。

---

## 体验改进

### Consumption Trends 页面

- 布局：控件 → 概览卡片 → 年度图表 → 分类矩阵 → 折叠式 movers
- Classification / Category L1 矩阵切换、CSV 导出、多年份列展示

### Reports 导航（6 组）

1. **Monthly overview** — Cashflow · Budget vs actual · Bills calendar  
2. **Year-over-year trends** — Income · Consumption · Debt  
3. **Spending analysis** — Fixed vs variable · Period comparison  
4. **Capital & taxes** — Fund flow · Transfers & investments · Tax summary  
5. **Forecast & risk** — Annual outlook · Cash risk  
6. **Merchants** — Subscriptions · Top merchants · Merchant changes  

### 命名统一

| 旧名 | 新名 |
| :--- | :--- |
| Spending Drift | **Period Comparison** |
| Transfer & Finance | **Transfers & Investments** |
| Merchant Concentration / Drift | **Top Merchants / Merchant Changes** |

面包屑：`Reports → 分组 → 报表`。

**功能开关：** Consumption / Income / Debt 三条 YoY 报表不再依赖 `forecast` feature flag。

---

## 修复

**趋势报表 semantic drill-down 返回 0 行**

- 原因：矩阵下钻同时传 `semanticFilter` 与 `consumeName`（展示标签），SQL AND 导致无结果
- 修复：有 semantic filter 时剥离 `consumeName`；日期统一 `YYYY-MM-DD`；前后端防御性处理
