## Summary

v2.0.3 builds on the v2.0.2 finance semantic layer with **Income**, **Consumption**, and **Debt** calendar-year YoY reports, a redesigned **Consumption Trends** page, and a decision-oriented **Reports** sidebar. All trend reports share the same semantic layer as Dashboard and Cashflow.

**No database migration** — application and frontend only.

---

## New features

### Year-over-year trend reports

| Report | Path | Purpose |
| :--- | :--- | :--- |
| **Income Trends** | `/app/reports/income-trends` | Calendar-year Real income YoY; classification / L1 matrix; drill-down |
| **Consumption Trends** | `/app/reports/trend-changes` | Living spend YoY; major page redesign |
| **Debt Trends** | `/app/reports/debt-trends` | Borrowing, repayments, net debt flow YoY; debt-pressure signal |

**New APIs:**

- `GET /api/v1/analytics/income-trends?fromYear=&toYear=&historyFromYear=`
- `GET /api/v1/analytics/debt-trends?fromYear=&toYear=&historyFromYear=`
- Enhanced `GET /api/v1/analytics/trends`

Backend: `IncomeTrendAnalysisService`, `DebtTrendAnalysisService`; extended `FinanceSemanticMetricsRepository` SQL.

---

## UX improvements

### Consumption Trends page

- Layout: controls → overview cards → yearly chart → matrix → collapsible movers
- Classification / Category L1 matrix toggle, CSV export, multi-year columns

### Reports navigation (six groups)

1. **Monthly overview** — Cashflow · Budget vs actual · Bills calendar  
2. **Year-over-year trends** — Income · Consumption · Debt  
3. **Spending analysis** — Fixed vs variable · Period comparison  
4. **Capital & taxes** — Fund flow · Transfers & investments · Tax summary  
5. **Forecast & risk** — Annual outlook · Cash risk  
6. **Merchants** — Subscriptions · Top merchants · Merchant changes  

### Renamed reports

| Before | After |
| :--- | :--- |
| Spending Drift | **Period Comparison** |
| Transfer & Finance | **Transfers & Investments** |
| Merchant Concentration / Drift | **Top Merchants / Merchant Changes** |

Breadcrumbs: `Reports → group → report`.

**Feature flags:** All three YoY trend reports are visible without the `forecast` flag.

---

## Fixes

**Trend report semantic drill-down returned zero rows**

- Cause: matrix drill sent both `semanticFilter` and `consumeName` (display label); SQL AND returned no rows
- Fix: strip `consumeName` when semantic filter is set; ISO dates; defensive handling in UI and services
