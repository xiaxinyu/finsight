# 文档阅读说明

| | |
| :--- | :--- |
| **Language** | 简体中文 · [English](_style-guide.md) |

FinSight 用户文档采用分层模块：**概念 → 页面指南 → 技术参考**。文中标记含义如下（非错误提示，不使用红色）：

| 标记 | 含义 |
| :--- | :--- |
| <span style="color:#2563eb">**核心**</span> | 必须理解的概念或 KPI |
| <span style="color:#059669">**计入**</span> | 纳入某指标的范围 |
| <span style="color:#d97706">**注意**</span> | 易误解或需单独查看 |
| <span style="color:#64748b">**参考**</span> | 延伸阅读或实现细节 |
