# Documentation reading guide

| | |
| :--- | :--- |
| **Language** | English · [简体中文](_style-guide.zh-cn.md) |

FinSight user docs use layered modules: **Concepts → Page guides → Technical reference**. Marker meanings (not error states — red is reserved for failures):

| Marker | Meaning |
| :--- | :--- |
| <span style="color:#2563eb">**Core**</span> | Concept or KPI you must understand |
| <span style="color:#059669">**Included**</span> | Counted in a metric or scope |
| <span style="color:#d97706">**Note**</span> | Easy to misread; check separately |
| <span style="color:#64748b">**Reference**</span> | Further reading or implementation detail |
